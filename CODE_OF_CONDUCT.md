# Code of Conduct · Кодекс поведінки

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful and constructive, assume good faith, and do not harass anyone. Report unacceptable behaviour privately to the maintainers through the repository's **Security → Report a vulnerability** form (see [SECURITY.md](SECURITY.md)).

Проєкт дотримується [Contributor Covenant, версія 2.1](https://www.contributor-covenant.org/uk/version/2/1/code_of_conduct/). Коротко: будьте шанобливими й конструктивними, припускайте добрі наміри, не допускайте цькування. Про неприйнятну поведінку повідомляйте супровідникам приватно через форму **Security → Report a vulnerability** у репозиторії (див. [SECURITY.uk.md](SECURITY.uk.md)).
